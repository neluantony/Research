# models/

Trained model weights and serialized objects (`.pt`, `.pkl`) live here.

This project does not store weights in the repository: the open-weight VLMs
(Qwen2.5-VL, Idefics2, SmolVLM, ...) are downloaded on demand inside Google
Colab, and the proprietary models (Gemini, Claude, GPT) are called through
their APIs. This directory is kept as a placeholder for any local checkpoint
produced later; large binaries stay out of git.
