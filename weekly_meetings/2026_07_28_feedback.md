# To-do list for next week

Before studying urban imageability or cognitive maps, we must first demonstrate that the proposed benchmark is technically sound. Specifically, we need to establish whether the models receive sufficient visual information to infer geographic location using only their internal representations.

## Experiment 1. Feasibility.

Use the current proposed design as the reference scenario:

- 50 cities.
- Approximately 200 sampled locations per city.
- Approximately 10,000 total locations.
- Several views or image configurations per location.
- At least six vision-language models (both proprietary and open-weight models).
- City-level and, where relevant, neighbourhood-level evaluation.

Do not assume that this design is feasible. The study must test and estimate its requirements.

Document the complete pipeline from beginning to end:

1. Select a city and sampling locations.
2. Query the Google Street View API.
3. Download, validate and store the images.
4. Prepare the visual input, such as a single image, four separate views or a composite grid.
5. Submit the input and prompt to each model.
6. Parse the model response.
7. Convert the predicted place into geographic coordinates.
8. Calculate country accuracy, city accuracy and localisation error.
9. Store the complete result and relevant metadata.

Check if the above pipeline is correct, and estimate:

- Execution Time
- Estimate Monetary Cost (if any)
- Test Data-Acquisition Scalability
- Compare Input Configurations

At the end of the feasibility study, recommend one concrete experimental design.

The recommendation must specify:

- Number of cities.
- Number of locations per city.
- Number of images or views per location.
- Models to include.
- Input format.
- Estimated total number of inference calls.
- Expected execution time.
- Expected monetary cost.
- Storage requirement.
- Necessary hardware.
- Main technical risks.
- Contingency plan if cost or runtime exceeds the estimate.


## Experiment 2. Evaluate the effect of visual context on geolocation performance.

For the initial 124 points, 12 cities, 3 LLMs, compare at least:

- Single Street View image
- Two opposite views
- Four cardinal directions
- $2 \times 2$ image grid (if feasible)

Measure:

- Country accuracy
- City accuracy
- Median localisation error

Question:

> Does providing additional visual context substantially improve localisation?

## Experiment 3. Are LLM measuring internal knowledge?

Verify that all evaluated models operate without:

- RAG
- Web search
- External APIs
- Document retrieval

Document precisely:

- Models used
- Inference environment
- Hardware
- Prompt
- Evidence that localisation relies only on internal model representations

## Experiment 4. Which models are suitable?

Evaluate several models spanning different capability levels.

Determine:

- Which models produce meaningful localisation.
- Which models are effectively guessing.

The goal is to identify the minimum capability required for the benchmark.
