Use this section to upload all your weekly meeting materials, including slides and meeting notes.

Better to use `.md` or, alternatively, `.pdf` files, which are better integrated with GitHub.

To keep the folder tidy:

- When uploading slides use the format: `yyyy_mm_dd_slides.pdf`
- Use mainly `.md` or `.pdf` files, instead of `.docx`, or `.ppt` files

**Important**. Upload slides in `.pdf`, not in other formats.
